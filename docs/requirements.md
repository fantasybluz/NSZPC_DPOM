# 需求

星辰電腦（NSZPC，高雄的客製化電腦組裝店）的內部管理系統 **DPOM**：庫存、訂單（報價）、客戶、叫貨結款、售後、社群數字，
都在這裡。對外的官網是另一個系統（`nszpc_web`），完成的訂單可以從這裡發布成官網的「出機紀錄」（[ADR 0003](decisions/0003-website-integration.md)）。

使用的人：店長（管理員）和員工，幾個人，用電腦和手機。現在先用 Cloudflare 免費方案給客戶 demo，確認要用再升級（[ADR 0001](decisions/0001-cloudflare-workers.md)）。

## 登入、權限

- 打開 https://dpom.bluz.dev，Cloudflare Access 要求登入：輸入 email、收驗證碼。**系統不存密碼**（[ADR 0002](decisions/0002-cloudflare-access.md)）
- 要用系統的人要加在兩個地方：Cloudflare Access 的允許清單、系統的「權限管理」（同一個 email）。只加在 Access 的人會看到「xxx 還沒開通」
- `BOOTSTRAP_ADMIN_EMAILS` 裡的 email 第一次登入自動變成管理員，之後由管理員加其他人
- 角色：
  - **管理員**：全部頁面，加上分類管理、權限管理、YouTube 金鑰設定
  - **一般使用者**：只看得到勾選的頁面。可以勾的：儀表板（也控制「報表/售後」）、庫存管理、訂單管理、叫貨管理、客戶管理、社群設定
- 管理員不能把自己降成一般使用者、停用自己、刪掉自己
- 停用的帳號登入後看到「這個帳號已停用」
- 登出：側欄的「登出」（Cloudflare Access 的登出）

> 頁面權限目前只控制側欄，後端只擋「管理員才能做」的那幾件事（見 [architecture.md](architecture.md#登入cloudflare-access)）。

## 庫存

### 分類

- 分類是一棵樹，層數不限（預設 CPU › AMD › AM5 三層、顯示卡 › 華碩兩層、記憶體一層）
- **商品只能放在最末端的分類**：已經有商品的分類不能再被當成別人的上層（新增子分類、移動分類時都檢查）
- 同一層的分類名稱不能重複
- 排序：**拖拉只在同一層**排（拖到別層不會動）；要換上層分類用「編輯」裡的「上層分類」（不能選自己或自己底下的），移過去放在最後面
- 刪分類會連子分類一起刪；底下有商品就不能刪
- 分類管理只有管理員能用（前端藏、後端也擋）

### 商品、批次

- 商品欄位：分類、品名（必填）、品牌、規格、售價、最低庫存警示、備註
- **數量和成本不能直接改**，只能透過進貨、出貨：
  - 新增商品時可以順便填「進貨數量、進貨單價、來源」，建一個「初始庫存」批次（數量、單價都大於 0 才建）
  - 進貨：數量、單價都要大於 0，每次進貨是一個批次
  - 出貨（手動）：數量不能大於現有的；原因預設「出貨」
- 數量 = 所有批次剩下的量加總；平均成本 = 剩下的量的加權平均
- 成本計算方式（`settings.cost_method`）：預設 **FIFO**（先進先出，從最舊的批次扣），也可以是加權平均（`average`，目前沒有畫面可以切換）
- 商品詳細：所有批次（進貨量、剩下、單價、來源、日期）、最新 50 筆異動、FIFO 成本（最舊還有剩的批次單價）和平均成本
- 低庫存：最低庫存設了（大於 0）而且數量小於等於它，儀表板和通知會列出來
- 刪商品會連批次、異動紀錄一起刪；訂單上的品項不受影響

## 訂單

（程式和舊文件裡叫「估價單」「quotation」，畫面上叫「訂單」。）

### 欄位

- 客戶（見下面「客戶關聯」）、品項標題（例如「白色海景房」）、需求地區、出貨日、出貨進度、訂金、服務費、備註
- 品項：分類、品名、規格、成本、售價、數量。可以從庫存選商品（記住 `inventory_id`，扣庫存用），也可以手打（不扣庫存）。同一個分類可以有很多項（兩條記憶體、三顆硬碟），可以拖拉排順序
- 單號自動產生：`Q` + 日期 + 當天流水號（`Q20261017001`）
- 金額由伺服器算：總成本 = Σ 成本 × 數量；**總價 = Σ 售價 × 數量 + 服務費**；毛利 = 總價 − 總成本；毛利率 = 毛利 / 總價
- 照片：存檔後在編輯畫面上傳，一次最多 10 張、每張 10MB，只收 JPG、PNG、WebP、GIF、HEIC、HEIF

### 狀態和扣庫存

| 狀態 | 畫面 | 庫存 |
|---|---|---|
| `draft` | 尚未成交 | 不扣 |
| `deposit` | 已付訂金 | 扣 |
| `pending` | 尚未結單 | 扣 |
| `completed` | 已完成 | 扣 |
| `cancelled` | 已取消 | 不扣（扣過的還回去） |

- 狀態可以任意改，不限順序；修改時沒帶狀態就維持原本的
- 從庫存選的品項，在訂單「成立」（已付訂金、尚未結單、已完成）時從批次扣（照成本計算方式，預設 FIFO）；每個批次扣了多少記下來，改回尚未成交、取消、刪單時照紀錄加回原批次（原批次被刪了就建一個新批次補回）
- 每次存檔都是「先還原、再照新內容重扣」，所以改品項數量、換商品都對得起來
- **庫存不足**（同一個商品的數量加總大於現有的）：新增的單不建、回錯誤；修改的單狀態改回「尚未成交」、回錯誤（其他欄位已經存了）
- 訂單扣庫存跟手動出貨一樣**看成本計算方式**：FIFO 從最舊的批次扣、異動成本照批次單價；加權平均照進貨順序扣、異動成本 = 平均成本 × 數量
- 出貨進度另外記：備料中、組裝中、測試中、待出貨、已出貨、已送達（跟庫存無關）

### 其他功能

- 列表篩選：狀態、出貨進度，搜尋單號、客戶名稱、客戶電話
- 複製訂單：變成新的一張「尚未成交」，訂金、出貨日、出貨進度清空，照片不複製
- 刪訂單：扣過的庫存還回去，照片、檢測表一起刪；有關聯的保固、維修工單留著，只是不再關聯這張單。全部一起成功或失敗，不會只刪一半。已經發布到官網的要先從官網拿掉（刪訂單不會動官網）

## 客戶

### 客戶資料

- 姓名、電話、email、來源（YouTube、Instagram、Line、門市、朋友介紹、其他）、縣市、區域、地址、備註
- 列表顯示**訂單數、成交金額**（只算已付訂金、尚未結單、已完成的）、**最近下單**；可以篩來源、縣市，搜尋姓名、電話、email
- 客戶詳細：聯絡資料、服務紀錄（可以新增、刪除）、他的所有訂單（點了打開那張），可以「幫他開新訂單」
- 地圖/圖表：客戶在台灣各縣市的分佈、來源分佈

### 客戶和訂單的關聯

- 訂單的客戶欄打字時下拉**相似的客戶**（[`CustomerPicker.tsx`](../frontend/src/components/CustomerPicker.tsx)），最多 8 個：
  名字完全一樣 > 開頭一樣 > 電話數字有對到（打 3 碼以上，不管 `-` 和空白）> 名字包含 > 名字有一半以上的字一樣（王小明 → 王曉明）。
  還沒打字時列出最近下單的客戶。↑↓ 選、Enter 確定、Esc 關
- 選了現有客戶：訂單關聯到他，名字用客戶管理裡的
- 打新名字時可以填電話；**電話跟現有客戶一樣**（8 碼以上）會提醒「這支電話是 xxx 的」，可以一鍵改用那位
- **新客戶什麼時候自動建**：存訂單時，打的是新名字、而且「狀態不是尚未成交」或「有填電話」，先建客戶再關聯（縣市、區域從需求地區拆）。
  尚未成交又沒電話的詢問不建，只在訂單上留名字
- **客戶改名**：他所有訂單上的名字跟著改
- **刪客戶**：他的訂單、保固、維修工單留著（名字還在），只是不再關聯；服務紀錄一起刪
- 訂單列表顯示客戶電話（從客戶資料即時帶），點名字到客戶資料；訂單詳細顯示客戶的聯絡資料和總共幾張單

## 發布到官網

把一張訂單變成星辰電腦官網的「出機紀錄」（[ADR 0003](decisions/0003-website-integration.md)）：

- 訂單列表或詳細按「發布到官網」，先帶好一份草稿可以改：
  - 日期 = 出貨日（沒有就今天）、標題 = 品項標題（沒有就「客製化主機」）、交機地區 = 需求地區
  - **售價 = 總價 − 服務費**（服務費不公開）
  - 狀態：出貨進度是已出貨 → 出貨中，其他 → 已交機（也可以選準備中、已取消）
  - 8 個規格（CPU、主機板、記憶體、硬碟、顯示卡、電源供應器、散熱、機殼）從品項的分類往上找第一層對應，同一類多項用「 / 」接，數量大於 1 加「x2」
  - 需求介紹、YouTube、標籤要自己填；標籤可以從官網用過的選
- **每個欄位都要有值**才能發布（前端先擋，官網也檢查）
- 照片：從訂單照片勾選，**最多 10 張、加起來 25MB 以內**，每張 10MB 以內；**只收 JPG、PNG、WebP、GIF**。
  HEIC／HEIF 多數瀏覽器看不到，在發布畫面顯示成不能選，並提示「HEIC 照片不能放上官網（多數瀏覽器看不到），請改傳 JPG」（訂單裡還是可以存 HEIC）
- **不帶任何客人資料**：姓名、電話、地址、成本、服務費都不會送到官網
- 發布過的再按一次是**更新同一筆**（照片整組換掉），也可以「從官網拿掉」（紀錄和照片都刪）
- 目前任何狀態的訂單都可以發布（照理是完成的訂單才發）

## 報價單

訂單的「產出報價單」（[ADR 0005](decisions/0005-quote-and-inspection-docs.md)）：

- A4 預覽：店名、店家資訊、報價單號、日期、客戶（姓名、電話、地址，從客戶資料帶）、品項（分類、品名規格、數量、金額）、服務費、總金額、訂金和尚需付款、有效期限、注意事項
- 下載 PDF、下載 JPG、產生圖片（可以一鍵複製貼到 LINE）
- 三段可以複製的文字：採購清單（只有品項）、文字版報價（貼 LINE）、匯款資訊（金額自動帶，有訂金就是尚需付款）
- 店名、店家資訊、有效期限、注意事項、匯款帳號、匯款說明可以改，所有報價單共用（存在設定 `quote_doc`）

## 出機檢測表

訂單的「出機檢測表」：

- 一張訂單一份，第一次打開用訂單帶草稿：報告編號 `QC-<出貨日>-<訂單編號>`、客戶、機器規格、Windows 11、測試人員（登入的人）、室溫 26°C
- **高壓測試**（預設 12 項：OCCT、Cinebench R23、AIDA64、FurMark、AS SSD…）：每列填最高溫度、最高功耗、時脈/分數、補充，狀態 正常／偏高／異常
- **逐項檢查**（預設 17 項，分「系統」「功能」兩段：驅動、BIOS、4K 對齊、待機/滿載瓦數、USB、音源孔、燈光…）：正常／異常／不適用
- 結論：檢測通過，可出機／有條件通過（見備註）／未通過，需處理，加注意事項
- 可以加減項目（高壓測試最多 40 列、檢查最多 80 項），存起來之後可以再改
- 匯出 PDF、JPG、貼 LINE 的圖片給客人

## 叫貨、盤商、結款

- 盤商：名稱（不能重複）、結款方式（週結、月結、貨到付款）、預設稅別（含稅、未稅）、聯絡方式、備註。有叫貨紀錄的盤商不能刪
- 叫貨單：盤商、訂購日、稅別、品項（品名、品牌、規格、數量、單價）
  - 含稅：稅額 = 小計 − 小計 / 1.05；未稅：稅額 0。總額都是小計
  - 狀態：**待到貨 → 已到貨**（按「確認到貨」，每一項選要入庫到哪個商品，選了的照數量、單價各建一個批次；沒選的不入庫）
  - **確認到貨只能按一次**：已到貨的再按、已取消的按，都會回錯誤，不會重複入庫
  - **取消叫貨**：只有待到貨的可以取消（紀錄留著，狀態「已取消」）；跟刪除不同。已取消的可以改回待到貨；已到貨的不能再改狀態
  - 刪叫貨單不會扣回已經入庫的庫存
- 統計：這週、這個月的叫貨總額，這個月各盤商的金額，這個月未結、已結的結款
- 結款：盤商、金額、稅別、期間、備註，狀態 尚未結款 → 已結款（按了記今天為付款日）

## 售後

### 保固

- 品名、序號、客戶、出貨日、保固月數（預設 12），到期日 = 出貨日 + 月數
- 狀態：**有效／已過期由到期日自動算**（過了到期日就顯示已過期，資料庫不改）；**已報修**是手動標記，可以改回
- 30 天內到期、還沒報修的列在通知
- 刪保固：關聯它的維修工單留著，只是不再關聯

### 維修工單

- 單號 `R` + 日期 + 流水號；客戶、設備、序號、問題、優先度（低、一般、急件、緊急）、備註
- 狀態：已收件 → 檢測中 → 維修中 → 等零件 → 已完成 → 已取件，或已取消；每次改狀態記一筆進度（可以寫說明）
- 改成已完成、已取件時記完成日；可以填診斷、處理方式、費用

### 通知

低庫存、30 天內到期的保固、未結款、進行中的維修（不是已完成、已取件、已取消的，緊急的排最前面：緊急 > 急件 > 一般 > 低）。

## 報表、匯出

- 利潤報表：只算**已完成**的訂單，每月或每年（最近 24 期）的張數、營收、成本、毛利、訂金；毛利前 20 的客戶、需求地區
- 匯出 CSV（Excel 打得開）：庫存、客戶、訂單、維修工單。金額、數量是 0 的照樣顯示 0；文字開頭是 `=`、`+`、`-`、`@` 的前面加 `'`，打開時不會被 Excel 當成公式執行

## 儀表板

庫存品項數、庫存成本、預計利潤、已完成訂單；這個月的訂單狀況（各狀態、出貨進度、最新 10 張）；
YouTube 訂閱數、IG 追蹤數；各分類的庫存數量、成本 vs 售價圖表；低庫存警示。

## 社群

- **YouTube**：管理員在「社群設定」填 API 金鑰和頻道 ID。訂閱數、觀看次數、影片數由伺服器去查，**每小時更新一次**，可以按「查詢」立刻更新。
  金鑰存了之後只顯示「已設定」，不會再送到瀏覽器（[ADR 0007](decisions/0007-social-server-side.md)）
- **Instagram**：IG 沒有開放查詢，追蹤數、追蹤中、貼文數手動填，記下更新時間

## 版號、更新紀錄

側欄最下面顯示版號，點進去是更新紀錄（`CHANGELOG.md`）；有沒看過的新版時版號旁邊顯示 NEW（[ADR 0009](decisions/0009-versioning.md)、[RELEASING.md](../RELEASING.md)）。

## 介面

- **日期都用台灣時間**：預設日期（服務紀錄、叫貨單、結款、保固、維修收件和完成日）、「今天」「這個月」的統計、保固是否過期都照台灣的今天算
- **Apple 風格**（[DESIGN.md](../DESIGN.md)，[ADR 0006](decisions/0006-apple-style.md)）：白底、淺灰區塊、強調色只有藍色 `#0066cc`、系統字型
- **手機也要能用**：側欄在手機變成從左邊滑出來，表格可以左右滑，表單一欄
- 側欄有「官網後台」連結（官網的推薦配單、文章在那邊管）

## 拿掉的、不做的

- **盤商報價**（貼 LINE 訊息或圖片解析報價）：使用者要求直接移除（[ADR 0004](decisions/0004-remove-supplier-quotes.md)）
- **LINE Notify 通知**：LINE Notify 在 2025-03-31 結束服務，拿掉了；之後要通知可以用 LINE Messaging API
- **IG 自動抓取**：IG 沒有開放查詢，改手動
- **下載備份按鈕**、社群設定裡的店家資訊卡：拿掉了（備份見 [setup.md](setup.md#備份與還原)，店家資訊在報價單設定）
- **帳號密碼登入、修改密碼**：改用 Cloudflare Access 後拿掉了
