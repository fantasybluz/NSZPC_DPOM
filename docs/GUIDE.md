## 登入

1. 用瀏覽器打開 <https://dpom.bluz.dev>
2. Cloudflare 會先要求登入：輸入你的 email，收信拿驗證碼，貼回去
3. 第一次用的人要先請管理員開通（要加在兩個地方，見 [setup.md](setup.md#加使用者)）；
   畫面出現「xxx 還沒開通」就是系統這邊還沒加
4. 系統不用密碼。登出請按側欄最下面的「登出」

## 儀表板

- 庫存品項、庫存成本、預計利潤（售價 − 成本）、已完成訂單
- 這個月的訂單狀況：各狀態幾張、出貨進度、最新 10 張
- YouTube 訂閱數、IG 追蹤數
- 各分類的庫存數量、成本 vs 售價圖表
- 低庫存警示：設了最低庫存、而且數量小於等於它的商品

## 庫存管理

左邊是分類樹，點分類只看那個分類（含底下的子分類）；上面的搜尋框找品名、品牌。

### 新增商品

1. 按右上角 **＋ 新增**
2. 填：
   - **分類**（必填，只能選最末端的分類）、**品名**（必填）、品牌、規格、售價、最低庫存警示、備註
   - 已經有貨的話順便填 **進貨數量、進貨單價、進貨來源**，會建一筆「初始庫存」
3. 儲存

### 進貨、出貨

**數量和成本不能直接改**，一律用進貨、出貨：

- **進貨**（列表每一列的進貨按鈕）：數量、進貨單價、來源、備註。每次進貨是一個「批次」
- **出貨**（手動出貨，例如零售、報廢）：數量、原因。成本預設照 **FIFO**（先進先出，從最早進的那批扣）
- 訂單用到的零件不用手動出貨，訂單成立時會自動扣（見下面「訂單管理」）
- 叫貨到貨時可以直接入庫（見「叫貨管理」）

點商品名稱可以看詳細：每個批次（進了多少、還剩多少、單價）、最近 50 筆異動、FIFO 成本和平均成本。

## 分類管理

只有管理員看得到。

- 分類可以有很多層，例如 **CPU › AMD › AM5**、**顯示卡 › 華碩**
- 拖拉分類左邊的把手排順序：**只能在同一層**排
- 要移到別的分類底下：按編輯，改「上層分類」
- 已經有商品的分類不能再放子分類（商品只能放在最末端）
- 刪分類會連子分類一起刪；底下有商品就刪不掉

## 訂單管理

### 建立訂單

1. 按 **＋ 新增訂單**
2. **客戶**：打名字或電話，下拉會列出相似的客戶（名字相近、電話不管有沒有 `-` 都找得到），選了就關聯到客戶管理
   - 是新客人：直接打名字，可以順便填電話。電話跟現有客戶一樣會提醒你，可以一鍵改用那位
   - 新客人在「狀態不是尚未成交」或「有填電話」時，存檔會自動建到客戶管理；只是詢問（尚未成交、沒電話）的不會建
3. **品項**：按 **＋ 新增項目**，選分類、品名（可以從庫存選，選了的訂單成立時會扣庫存）、規格、成本、售價、數量。同一個分類可以加很多項，可以拖拉排順序
4. **服務費**（組裝、燒機、系統安裝）、訂金、品項標題、需求地區、出貨日、出貨進度、備註
5. 系統自動算：
   - **總成本** = 每項成本 × 數量加總
   - **總價** = 每項售價 × 數量加總 + 服務費
   - **毛利** = 總價 − 總成本，**毛利率** = 毛利 / 總價

### 狀態

```
尚未成交 → 已付訂金 → 尚未結單 → 已完成
                                 ↘ 已取消
```

- 改成 **已付訂金、尚未結單、已完成** 時，從庫存選的零件會自動扣庫存；改回尚未成交、取消或刪掉訂單時會還回去
- 庫存不夠時存不進去（或狀態被改回尚未成交），畫面會說哪一項缺多少
- 出貨進度另外選：備料中、組裝中、測試中、待出貨、已出貨、已送達

### 照片

先存檔，再按編輯，在下面上傳。一次最多 10 張、每張 10MB，只收 JPG、PNG、WebP、GIF、HEIC。

### 產出報價單

按訂單的報價單按鈕：

- 看到 A4 的報價單，可以 **下載 PDF**、**下載 JPG**、**產生圖片（貼 LINE）** 再按「複製圖片」
- 下面三段文字可以直接複製：採購清單、文字版報價（貼 LINE）、匯款資訊
- 店名、地址、注意事項、匯款帳號可以按「編輯」改，所有報價單共用

### 出機檢測表

按訂單的檢測表按鈕：第一次會用訂單帶好規格和預設的測試項目，填上實測的溫度、功耗、分數和每一項的結果，選結論，**儲存**。
之後可以下載 PDF、JPG 或產生圖片給客人。

### 發布到官網

按訂單的地球按鈕：

- 規格、售價（總價 − 服務費）、日期、地區都帶好了，補上 **需求介紹、標籤**（YouTube 可以不填），勾要放的照片（最多 10 張、加起來 25MB 以內）。**HEIC 照片不能放上官網**（iPhone 預設的格式，多數瀏覽器看不到），會顯示成灰色不能選，請改傳 JPG（iPhone：設定 › 相機 › 格式 › 最相容）
- 官網上**不會**出現客人姓名、電話、成本、服務費
- 發布過的再按一次是更新同一筆；也可以「從官網拿掉」
- 刪訂單不會刪官網那筆，要先拿掉

### 其他

- 篩選狀態、出貨進度，搜尋單號、客戶名稱、電話
- **複製訂單**：變成新的一張尚未成交的單（訂金、出貨日清空，照片不會複製）

## 客戶管理

- 新增客戶：姓名（必填）、電話、email、來源（YouTube、Instagram、Line、門市、朋友介紹、其他）、縣市、區域、地址、備註
- 列表看得到每位客戶的訂單數、成交金額、最近下單
- 點客戶看詳細：服務紀錄（可以新增、刪除）、他的所有訂單，按 **幫他開新訂單** 直接開一張
- 客戶改名，他的訂單上的名字會跟著改；刪客戶時訂單會留著
- **地圖/圖表**：客戶在各縣市的分佈、來源分佈

## 叫貨管理

### 盤商

**＋ 新增盤商**：名稱、結款方式（週結、月結、貨到付款）、預設稅別（含稅、未稅）、聯絡方式。有叫貨紀錄的盤商不能刪。

### 叫貨

1. **＋ 新增進貨**：選盤商、日期、稅別，加品項（品名、品牌、規格、數量、單價）
   - 含稅：系統拆出 5% 的稅額；未稅：稅額 0
2. 貨到了按 ✓（**確認到貨入庫**）：每一項選要入庫到哪個庫存商品，選了的會照數量、單價進貨；不選的不入庫
3. 盤商沒貨、不要了：按 ⓧ（**取消叫貨**，只有待到貨的可以），紀錄會留著；刪除是整筆刪掉

### 結款

**＋ 新增結款**：盤商、金額、稅別、期間。付了按 ✓（**標記已結款**），記今天是付款日。

## 報表、保固、維修

- **利潤報表**：只算已完成的訂單，每月或每年的營收、成本、利潤，利潤最高的客戶、地區
- **保固**：**＋ 新增保固**，填品名、序號、客戶、出貨日、保固月數（預設 12）。過了到期日自動顯示「已過期」；客人來報修時標記「已報修」
- **維修工單**：**＋ 新增工單**，之後每次改狀態（已收件 → 檢測中 → 維修中 → 等零件 → 已完成 → 已取件）都會記一筆進度
- **通知**：低庫存、30 天內到期的保固、還沒結的款、進行中的維修
- **匯出**：庫存、客戶、訂單、維修工單的 CSV（Excel 打得開）

## 社群設定

### YouTube

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建專案、啟用 **YouTube Data API v3**、建立 API 金鑰
2. 頻道 ID：頻道網址裡 `UC` 開頭的那串（或 YouTube 的進階設定）
3. 在社群設定貼上 API Key 和頻道 ID，按 **儲存**（只有管理員可以存）。金鑰存了之後只顯示「已設定」，要換才重填，留空是不改
4. 按 **查詢** 看訂閱數、觀看次數、影片數；儀表板也會顯示，每小時更新一次

### Instagram

IG 沒有開放查詢，按 **手動輸入** 填追蹤數、追蹤中、貼文數。

## 權限管理

只有管理員看得到。

1. **＋ 新增使用者**：填 email（要跟他登入 Cloudflare 用的一樣）、顯示名稱
   - 同一個 email 也要加進 Cloudflare Access 的允許清單（見 [setup.md](setup.md#加使用者)），兩邊都有才進得來
2. 角色：
   - **管理員**：全部頁面，加上分類管理、權限管理
   - **使用者**：只看得到勾選的頁面
3. 勾選頁面：儀表板（也控制「報表/售後」）、庫存管理、訂單管理、叫貨管理、客戶管理、社群追蹤 / 設定
   - 畫面上還有「結款管理」「報表/保固/維修」兩個選項，目前勾了沒有作用（結款在叫貨管理裡、報表跟著儀表板）
4. **停用**：把狀態改成停用，他就進不來了。員工離職時停用，並從 Cloudflare Access 的允許清單拿掉
